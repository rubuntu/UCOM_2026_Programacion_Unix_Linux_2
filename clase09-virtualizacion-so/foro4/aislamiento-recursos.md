# Foro 4: Aislamiento de Recursos y Seguridad en cgroups

### Consigna de Debate
> *"Si un proceso dentro de un contenedor Linux tiene permisos de superusuario (UID 0), ¿puede vulnerar el aislamiento si no se utiliza User Namespaces? ¿De qué manera los cgroups v2 previenen ataques de denegación de servicio (DoS) por agotamiento de descriptores o memoria?"*

### Requisitos de Participación:
- Realizar una intervención fundamentada citando conceptos de la clase.
- Replicar a la respuesta de al menos un compañero aportando un caso real o comando de diagnóstico.
